# Manganese-Mines-HTML-
Smart India Hackathon 2026 (SIH 2026)   
Challenge ID: SIH26009   
Team: IIM Mumbai Team   

The system is about making a model for satellite sensing on manganese mines' geographical structures and then using AI to estimate more possible sites of manganese deposits.
Between macro-level remote sensing and micro-level subsurface exploration by fusing multi-spectral satellite rasters (such as Sentinel-2 and ISRO Bhuvan) with legacy borehole drill logs and official geological distributions. This multi-layered approach will dramatically optimize subsurface mineral reserve mapping and improve grade estimation accuracy, and maximize fleet allocation efficiency across active mining sites.   

Expected Exploration Cost Reduction: Achieves a 30 to 40 percent reduction in exploratory drilling costs through precise AI-generated subsurface heatmaps.  
Drilling Hit Rate: Elevates core drilling success rates to between 65 and 80 percent using the hybrid AI and core-fused geological model. 

Bonai-Kendujhar Basin (Odisha), Sandur-Hospet Belt (Karnataka), Balaghat Belt (Madhya Pradesh / Maharashtra) and some other regions are included as demos from mock data.

Built with HTML5 and CSS3 structures ensuring high-performance dashboard rendering across field and office terminals.   
Spatial Telemetry and Simulation Engine: Currently Powered by PyScript and NumPy libraries, enabling the execution of real-time Python-based subsurface deposit simulations directly within the web browser environment.   
Includes regional mine cluster selection interfaces, high-grade core identification legends, and pan-enabled telemetry grid feeds for geological auditing based on mock data as of yet.
